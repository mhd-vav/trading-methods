# Trading Methods Knowledge Base

A systematically researched, open-source knowledge base of trading styles and methods — every method documented with educational material, working references, and source links.

## Structure

This repository has one **branch per trading method/style**. The `main` branch holds the project overview and master index.

## Method Index

See `METHODS.md` for the full taxonomy and per-method branches.
